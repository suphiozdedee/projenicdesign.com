## The Zero-AI Audit Matrix

Before ANY design or code is approved, audit line-by-line:

| Audit Category | Rejection Trigger (VETO) | Approval Requirement |
|---|---|---|
| **Typography** | Font is `Inter`, `Roboto`, `Arial` or `Helvetica` | Font is `Plus Jakarta Sans`, `Geist`, `Clash Display`, or `PP Editorial New` |
| **Letter Spacing** | Headlines have default tracking (`0em`) | Headlines have negative tracking (`-0.035em`) |
| **Corners** | Inner corner radius $\neq$ Outer Radius $-$ Padding | Concentric Corner Law mathematically satisfied |
| **Icons** | Thick FontAwesome or Material Icons | Hairline 1px SVGs or Phosphor Light icons |
| **Borders** | Solid 1px gray borders (`#ccc`, `border-gray-700`) | Semi-transparent hairlines (`white/10`) + top inset highlight |
| **Navbar** | Sticky full-width top box glued to 0px | Floating Island Pill with backdrop blur |
| **Buttons** | Flat rectangular buttons with plain text | Strict `32/40/48px` matrix with nested trailing icon badge |

## Enforcement
If even a **single line** triggers a rejection condition, issue an immediate **VETO & REJECT** directive with exact replacement code.
